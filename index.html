            How it was built

            Methodology

            1. Prepare the dataReview dataset structure and attributes, standardize column naming, and prepare for SQL querying and Tableau visualization.
            2. Engineer risk segmentsCreate Credit Score Band, DTI Band, EMI to Income Ratio and Tenure Stability fields.
            3. Analyze with SQLCalculate default rates, analyze borrower demographics, evaluate loan-purpose risk, measure credit-score performance, and assess DTI and employment-related risk.
            4. Build the Tableau dashboardA single-page dashboard with KPI cards, loan-purpose and credit-score risk views, DTI risk, employment stability, and interactive filters.

            Project objectives

              Key findings

              • Weaker credit, higher default.Borrowers with weaker credit profiles generally exhibited higher default rates.
              • Debt burden matters.Higher debt burdens were associated with increased repayment risk.
              • Purpose matters.Certain loan purposes demonstrated greater default tendencies than others.
              • Employment stability matters.Employment stability appeared to influence repayment performance.
              • Risk factors compound.Combining multiple risk factors resulted in significantly higher default probabilities.

              Conclusion

              This project demonstrates how data analytics can be leveraged to understand loan default behavior and improve lending decisions. By combining SQL-based analysis with Tableau visualization, meaningful insights were generated regarding borrower risk, credit quality and portfolio performance. The findings can assist financial institutions in reducing default rates while maintaining sustainable loan growth.
